# Ciel (시엘) — Wuthering Waves Style Interactive 3D Viewer

100% natively procedural **Blender 5.2 LTS** 3D virtual idol character (**Ciel / 시엘**) rendered live on the web with **Three.js (WebGL2 / glTF 2.0)**.

- **Live Web Viewer**: [https://gituserkhs.github.io/ciel-3d-viewer/](https://gituserkhs.github.io/ciel-3d-viewer/)
- **Rig**: 94-bone humanoid + 5-finger articulated hands + hair & organza secondary bones
- **Morph Targets**: `Smile_Happy`, `Surprised`, `Sad_Worried`, `Blink`, `Blink_L`, `Blink_R`, and VRM visemes
- **Controls**: Drag to orbit, scroll to zoom, right-drag to pan, switch expressions / poses / camera presets, or open the Cycles OPTIX Studio Render Gallery.
